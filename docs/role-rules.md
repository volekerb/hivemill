# Role rules from lessons

Each of `roles/_common.md`, `boss.md`, `director.md`, `lead.md`, `coder.md` and `reviewer.md` ends with a `## Standing rules (lessons)` section. A rule is one imperative line that ends with its source in parentheses (an M-id, task id or lesson id). Long guidance lives in per-role skills instead: `roles/plugins/director/` has `owner-decisions` (owner rule M833) and `restriction-check` (automated writers, M733), and `roles/plugins/pm/` has `audit-scope`. `tests/test_role_rules.py` checks that each rule is present under that heading. New spawns read changed role files at once; persistent agents need `factory relaunch <name> --when-idle`. Total prompt size per role is capped by `tests/test_repo_hygiene.py` (12000 bytes of `_common.md` plus the role file).
