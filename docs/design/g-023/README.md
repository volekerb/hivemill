Three draft layouts for the Hivemill README v2, written as plain GitHub markdown for owner preview. Nothing here replaces the root README.

| Option | Idea |
|---|---|
| [A: Showcase](readme-option-a.md) | Product page: wordmark, video, big screenshot, feature grid |

Notes for whoever builds the chosen one:

- Screenshots are the G-019 shots in `../g-019/shots` and the wordmark in `../../images`, used as placeholders.
