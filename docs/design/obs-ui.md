# obs UI design direction

First version: headings only; the sections are filled in the next commit.

## Direction
Modern product UI for engineers: dense information, calm type, strong hierarchy, motion only where it explains state.

## Tokens
Light and dark: colour, type scale, spacing.

## Pages
Now, Spend, Flow, Machines and the `/task/T-x` trace page.

## States
Empty, loading, error.

## Accessibility
WCAG AA contrast targets and reduced motion.

## Constraints
Read-only; works without script where it does today.

## UI skills
ui-ux-pro-max, taste-skill, impeccable.
