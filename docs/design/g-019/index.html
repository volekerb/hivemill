Hivemill web UI redesign: static mockups

G-019 B1 for approval. Six pages as hand-written HTML and one stylesheet, light and dark (follows the OS; the screenshots in shots/ force each theme), desktop 1280 x 860 and phone 390 x 844. No JavaScript, no external requests, system fonts only. Read README.md for the brief summary, the screenshot table and the checks.

Pages

OverviewOperator cockpit: needs you, system gauges, goals, agents, shipped, quality (J1-J6).GoalsOpen goals with progress meters, criteria and blocking reasons.Goal detailG-002: what is blocking, success criteria with task glyphs, grouped tasks, right rail.AgentsRunning agents grouped by team, queued with reasons, teams, recently ended.TasksFilter chips with counts, tasks grouped by status, sortable columns.QualityHeadline tiles with deltas, bouncing tasks, per team, by source, per week.

Direction in six lines

  • Answer first: every page opens with what needs you, is it healthy, what changed.
  • Colour means state only; one blue accent for interaction; every status has a shape and a word.
  • Quiet structure: grouped lists on a neutral canvas, hairlines instead of boxes, one type family in three weights.
  • Dense, never empty: 36 px rows on desktop, 44 px on phone, overview blank area under 35%.
  • Same thing, same component, same word on every page.
  • Light and dark designed together, WCAG AA for every token pair, no sideways scroll at 390 px, complete without JavaScript.
