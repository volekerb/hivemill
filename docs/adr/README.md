# Architecture decision records

ADRs record decisions that are hard to reverse, surprising without context, and the result of a real trade-off.
Files are numbered `NNNN-slug.md` in this directory; the number never changes once merged, because roles and
skills link to the path.

Each ADR has these sections: **Status** (Proposed, Accepted, Deprecated, or Superseded by ADR-NNNN), **Context**,
**Decision**, **Consequences**, **Alternatives**. Longer ADRs may split the Decision into several headed sections.
A Proposed ADR becomes Accepted only with the approving message id recorded in its Status section.
